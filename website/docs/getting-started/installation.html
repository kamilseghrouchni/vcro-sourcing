Installation

One command. No package manager. Stdlib Python only.

Quick install

curl -fsSL https://vcro.bio/install | bash

This downloads the installer, copies the CLI, skills, agents, rules, hooks, and a wiki skeleton into ./vcro. No pip. No wheels. No dependency tree.

Requirements

  • Claude Code -- the CLI must be on your PATH. Install with curl -fsSL https://claude.ai/install.sh | bash
  • Python 3.10+ -- all scripts are stdlib only. No third-party packages at runtime.
  • macOS or Linux -- POSIX shell. Windows via WSL.

Installer flags

bash scripts/install.sh [--target DIR] [--from-local PATH | --version TAG]
                        [--skills-only] [--force]

--target DIR

Install prefix. Default: ./vcro.

--skills-only

Copy only the agent surface: .claude/{skills,rules,agents,hooks}, bin/vcro, and scripts/. Skips the store/ skeleton. Use this when you already have a Claude Code project and want to add vCRO skills to it.

--version TAG

Pin to a specific release tag. Default: latest. Downloads a tarball from GitHub releases.

--from-local PATH

Copy from a local repo checkout instead of downloading. Mutually exclusive with --version. Useful for development.

--force

Overwrite an existing target directory.

What gets installed

vcro/
  bin/vcro                  # CLI entry point
  scripts/                  # Pure Python plumbing (ingest, index, lint, telemetry)
  .claude/
    agents/                 # vcro-os, vcro-bounty, vcro-onboard
    skills/                 # 17 phase-level skills
    rules/                  # 9 rule files + commandments
    hooks/                  # Entity schema validation, reindex, commit authorship
    commands/               # Slash command definitions
  store/                    # Wiki skeleton (skipped with --skills-only)
    wiki/{cohorts,institutions,...,index/}
    raw/{papers,trials}/
    queries/
    runs/
    lint/
  CLAUDE.md                 # Project instructions for Claude Code
  vcro-skills-lock.json     # Integrity lockfile (if present)

Verify

./vcro/bin/vcro version
./vcro/bin/vcro help
